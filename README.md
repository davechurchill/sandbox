# MUN AI & Games Lab Augmented Reality Sandbox

![Sandbox](https://davechurchill.ca/files/images/sandbox/sandbox_github.jpg)

An interactive augmented-reality sandbox that turns live or generated height maps into projected terrain, simulations, and composited visual effects.

[Sandbox image gallery](https://davechurchill.ca/files/images/sandbox/)

## At a glance

The physical installation uses a Windows computer, an Intel RealSense D455 depth camera, a projector, and a sandbox. The C++20 application uses SFML 3, ImGui-SFML, the Intel RealSense SDK, and OpenCV 4.8.0.

See the [Installation guide](https://github.com/davechurchill/sandbox/wiki/Installation) for dependencies and build instructions.
